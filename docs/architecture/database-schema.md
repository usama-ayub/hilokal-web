# MongoDB Database Schema Specification

This document details the MongoDB collections, documents, field validations, and indexes designed for the Hilokal Clone Web application.

---

## 1. Collection: `users`
Stores core authentication and identity data.

```json
{
  "_id": "ObjectId",
  "username": "string (unique, indexed, lowercase, alphanumeric)",
  "email": "string (unique, indexed, lowercase)",
  "passwordHash": "string",
  "displayName": "string",
  "avatarUrl": "string (URL to MinIO/S3)",
  "audioBioUrl": "string (URL to 30s audio recording in MinIO)",
  "bio": "string (max 280 chars)",
  "countryCode": "string (2-letter ISO, e.g., 'PK', 'US', 'TR')",
  "isVip": "boolean (default: true - Unlocked Free for all)",
  "coinsBalance": "number (default: 500 - Daily free coins)",
  "currentStreak": "number (default: 0)",
  "lastActiveAt": "Date",
  "createdAt": "Date",
  "updatedAt": "Date"
}
```

### Indexes:
* `{ username: 1 }` (Unique)
* `{ email: 1 }` (Unique)
* `{ coinsBalance: 1 }`

---

## 2. Collection: `user_languages`
Tracks native languages and languages being learned along with CEFR proficiency levels.

```json
{
  "_id": "ObjectId",
  "userId": "ObjectId (ref: users, indexed)",
  "languageCode": "string (e.g., 'en', 'es', 'ur', 'ja')",
  "type": "string (enum: ['native', 'learning'])",
  "proficiency": "string (enum: ['A1', 'A2', 'B1', 'B2', 'C1', 'C2', 'native'])",
  "isPrimaryLearning": "boolean (default: false)",
  "createdAt": "Date"
}
```

### Indexes:
* `{ userId: 1, languageCode: 1 }` (Compound Unique)
* `{ languageCode: 1, type: 1 }` (For searching partners by language)

---

## 3. Collection: `rooms` (Tables)
Stores metadata for live and historical audio tables.

```json
{
  "_id": "ObjectId",
  "title": "string (max 100 chars)",
  "description": "string (optional)",
  "primaryLanguage": "string (e.g., 'en')",
  "targetLevel": "string (enum: ['all', 'beginner', 'intermediate', 'advanced'])",
  "topicTag": "string (e.g., 'Casual Chat', 'IELTS Prep', 'Business', 'Grammar')",
  "bannerUrl": "string (optional, free custom room banner)",
  "hostId": "ObjectId (ref: users, indexed)",
  "status": "string (enum: ['active', 'ended'], default: 'active', indexed)",
  "isPrivate": "boolean (default: false)",
  "maxSpeakers": "number (default: 8, max: 12)",
  "livekitRoomName": "string (unique)",
  "totalParticipantsPeak": "number (default: 0)",
  "startedAt": "Date",
  "endedAt": "Date",
  "createdAt": "Date",
  "updatedAt": "Date"
}
```

### Indexes:
* `{ status: 1, primaryLanguage: 1 }`
* `{ hostId: 1 }`
* `{ livekitRoomName: 1 }` (Unique)

---

## 4. Collection: `scheduled_tables`
Allows hosts/tutors to schedule future live events with calendar reminders.

```json
{
  "_id": "ObjectId",
  "hostId": "ObjectId (ref: users, indexed)",
  "title": "string",
  "description": "string",
  "language": "string",
  "scheduledStartTime": "Date (indexed)",
  "estimatedDurationMinutes": "number (default: 60)",
  "interestedUserIds": ["ObjectId (ref: users)"],
  "status": "string (enum: ['scheduled', 'live', 'cancelled', 'completed'])",
  "createdAt": "Date"
}
```

### Indexes:
* `{ scheduledStartTime: 1, status: 1 }`
* `{ hostId: 1 }`

---

## 5. Collection: `room_messages`
Stores in-room text chat messages, corrections, and pinned announcements.

```json
{
  "_id": "ObjectId",
  "roomId": "ObjectId (ref: rooms, indexed)",
  "senderId": "ObjectId (ref: users)",
  "messageType": "string (enum: ['text', 'correction', 'gift', 'system'])",
  "content": "string",
  "correctionData": {
    "originalText": "string",
    "correctedText": "string",
    "explanation": "string"
  },
  "giftData": {
    "giftType": "string (e.g., 'coffee', 'rose', 'clap', 'star')",
    "coinAmount": "number",
    "recipientId": "ObjectId (ref: users)"
  },
  "createdAt": "Date (TTL index: 48 hours after room ends)"
}
```

### Indexes:
* `{ roomId: 1, createdAt: 1 }`

---

## 6. Collection: `ai_summaries`
Stores AI-generated transcripts, vocabulary flashcards, and conversation insights generated by the Google Gemini engine after room termination.

```json
{
  "_id": "ObjectId",
  "roomId": "ObjectId (ref: rooms, unique, indexed)",
  "summaryMarkdown": "string",
  "keyVocabulary": [
    {
      "word": "string",
      "phonetic": "string",
      "meaning": "string",
      "exampleUsage": "string"
    }
  ],
  "grammarNotes": ["string"],
  "createdAt": "Date"
}
```

---

## 7. Collection: `coin_transactions`
Logs all free virtual currency allocations and gift exchanges for auditing and gamification.

```json
{
  "_id": "ObjectId",
  "userId": "ObjectId (ref: users, indexed)",
  "type": "string (enum: ['daily_bonus', 'gift_sent', 'gift_received', 'streak_reward'])",
  "amount": "number",
  "relatedUserId": "ObjectId (ref: users, optional)",
  "roomId": "ObjectId (ref: rooms, optional)",
  "createdAt": "Date"
}
```
