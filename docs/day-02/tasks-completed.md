### 2. Domain Data Models (Mongoose & TypeScript)
Implemented 7 robust Mongoose models in `src/models/` with TypeScript interfaces and compound indexes:

1. **`User` (`src/models/User.ts`):**
   * Core identity, credentials, profile bio, avatar URL, and audio bio URL.
   * **100% Free VIP:** Built-in default `isVip: true` for all users.
   * **Free Coins Allocation:** Built-in default `coinsBalance: 500` (auto-renewed daily, zero billing gateways).
   * Daily streak tracking and cumulative speaking minutes.

2. **`UserLanguage` (`src/models/UserLanguage.ts`):**
   * Language portfolio management for native and learning languages.
   * Standard CEFR proficiency mapping: `A1`, `A2`, `B1`, `B2`, `C1`, `C2`, `native`.
   * Primary target learning flag for room recommendations.
   * Compound unique index on `{ userId: 1, languageCode: 1 }`.

3. **`Room` (`src/models/Room.ts`):**
   * Real-time audio tables supporting `casual`, `practice`, `lesson`, and `debate` formats.
   * Configurable speaker limits (2 to 10 slots, default 6).
   * Custom room banner uploads (unlocked for all hosts).
   * Status lifecycle (`active` vs. `ended`) with compound indexing for language and active status discovery.

4. **`ScheduledTable` (`src/models/ScheduledTable.ts`):**
   * Upcoming events and tutor table scheduling.
   * RSVP list with user references and notification reminder flags.
   * Status lifecycle (`scheduled`, `live`, `completed`, `cancelled`).

5. **`RoomMessage` (`src/models/RoomMessage.ts`):**
   * Real-time in-room communication supporting `text`, `correction`, `gift`, and `system` message types.
   * Instant peer vocabulary correction schema (`originalText`, `correctedText`, `explanation`).
   * Virtual gift ledger records (`giftType`, `coinCost`, `recipientId`).

6. **`AiSummary` (`src/models/AiSummary.ts`):**
   * Automated discussion summary and vocabulary flashcards generated by Google Gemini free tier.
   * Extracted vocabulary objects (`word`, `definition`, `exampleSentence`, `translation`).
   * CEFR grammar suggestions (`original`, `suggestion`, `rule`).
   * Key phrases and talking point highlights.

7. **`CoinTransaction` (`src/models/CoinTransaction.ts`):**
   * Audit trail for free coin movements: `initial_signup`, `daily_login_bonus`, `streak_reward`, `sent_gift`, `received_gift`, `host_tip`.
   * Running balance verification (`balanceAfter`).
   * Zero real-money or credit card logic.

8. **Barrel Export (`src/models/index.ts`):**
   * Unified export allowing clean imports: `import { User, Room, ... } from "@/models"`.

### 3. Media Storage Pipeline & Multipart Upload API
* **Multipart Upload API Route (`src/app/api/media/upload/route.ts`):**
  * Accepts `multipart/form-data` for three dedicated buckets: `avatars`, `room-banners`, and `audio-bios`.
  * Strict MIME type whitelisting for images (JPEG, PNG, WebP, GIF) and audio (MP3, WAV, WebM, OGG, M4A).
  * Strict file size enforcement: Max 5MB for images, Max 10MB for audio recordings.
  * Sanitized unique file naming using timestamp and UUID to prevent collisions.
  * Automatically stores files to `public/uploads/<bucket>/` and returns the public HTTP URL.

* **Client-Side Media Service (`src/lib/media-service.ts`):**
  * Reusable frontend utility functions: `uploadMedia`, `uploadAvatar`, `uploadRoomBanner`, and `uploadAudioBio`.
